---
description: 최근 커밋/변경 내역을 요약해 이 프로젝트의 현재 상태를 파악
---

이 프로젝트로 돌아왔어. 현재 상태를 파악해줘.

1. `git log`(최근 10~15개 커밋)와 `git status`, `git diff`(unstaged/staged)를 확인해.
2. 최근에 어떤 작업이 진행되고 있었는지, 커밋 메시지와 diff를 근거로 요약해.
3. 커밋되지 않은 변경이나 미완성으로 보이는 작업이 있으면 짚어줘.
4. 다음으로 이어서 할 만한 작업이 있으면 제안해.

코드를 수정하지 말고, 짧은 요약만 보고해줘.
