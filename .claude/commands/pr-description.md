---
description: 현재 브랜치의 변경사항을 바탕으로 PR 제목/설명 초안 작성
---

현재 브랜치와 기본 브랜치(main/master) 사이의 차이를 바탕으로 PR 제목과 설명 초안을 작성해줘.

1. `git log <base>..HEAD`와 `git diff <base>...HEAD`로 이 브랜치의 전체 커밋을 확인해(마지막 커밋만 보지 말고).
2. 제목은 70자 이내로 간결하게.
3. 설명은 "무엇을 왜 바꿨는지" 요약 bullet + 필요하면 테스트 방법 체크리스트로 구성해.
4. PR을 실제로 만들지는 말고, 초안 텍스트만 보여줘. 만들어달라고 하면 그때 `gh pr create`로 진행해.
